# 2026-06-04 工作日志

## 方案细节验证（playwright codegen + HAR + playwright-healer + haralyzer + 百炼DeepSeek）

### 已验证的关键信息
1. **playwright codegen CLI** 支持 `--save-har`、`--save-har-glob`、`--output`、`--target=python-pytest`、`--load-storage`，一条命令同时完成 UI 录制 + HAR 网络捕获
2. **playwright-healer v1.0.7**（PyPI）：5层自愈流水线（原始→缓存→启发式→DOM模糊→AI DOM→AI视觉），支持 DeepSeek provider，pytest `healing_page` fixture，自动源码修补
3. **haralyzer v2.4.0**（PyPI）：3个核心类 HarParser/HarPage/HarEntry，支持解析 HAR 1.2 标准，文档不太完善但功能够用
4. **@testmate-agent/core** 确实存在（npm v0.1.0，2026-05-07发布），但：语言是 TypeScript、README 土耳其语、强制绑定 Anthropic Claude API、几乎无下载量、与 playwright-healer 功能完全重叠
5. **百炼 DeepSeek** 使用 OpenAI 兼容模式（`https://dashscope.aliyuncs.com/compatible-mode/v1`），与 playwright-healer 的 DeepSeek provider 兼容（需确认是否支持自定义 base_url）

### 关键风险点
- playwright-healer 的 DeepSeek provider 是否支持自定义 base_url（百炼 endpoint 不同于官方 DeepSeek）
- haralyzer 文档 404，可能需要查看源码或 pip install 后用 help() 确认 API
- playwright-healer 异步优先（async/await），需要确认同步 API 支持程度

## ZeroStep 评估

### 结论：不适用
- ZeroStep 仅有 npm 包 `@zerostep/playwright`，PyPI 上无任何 Python 包
- 后端绑定 OpenAI GPT-3.5/GPT-4，百炼 DeepSeek 用不了
- SaaS 按调用计费（Free 500次/月，Team $20/月），成本不可控
- 隐式自愈（自然语言替代选择器）不确定，每次 AI 重新决策

### 三款自愈框架终极对比结论
- playwright-healer ✅：Python 原生 + DeepSeek 可用 + 免费 + 确定性修复
- ZeroStep ❌：TypeScript + 强制 OpenAI + SaaS 付费 + 非确定
- @testmate-agent/core ❌：TypeScript + 强制 Anthropic + v0.1.0 + 无社区
