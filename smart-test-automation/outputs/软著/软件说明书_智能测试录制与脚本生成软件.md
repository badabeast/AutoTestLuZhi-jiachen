# 软件说明书

# 智能测试录制与脚本生成软件 V1.0

---

## 1 软件概述

### 1.1 软件名称

智能测试录制与脚本生成软件（以下简称"本软件"）

### 1.2 软件版本

V1.0

### 1.3 软件功能简介

本软件是一款面向Web应用自动化测试的智能录制与脚本生成工具。通过独创的两步录制法，第一步录制用户在浏览器中的UI操作并生成原始测试脚本，第二步自动回放脚本同时捕获完整的API请求/响应数据（HAR）和执行追踪（Trace），实现UI操作与API数据的自动关联。软件内置AST语法树解析器，可精确提取UI操作语义，并自动清洗录制噪音，生成可直接用于自动化测试的增强脚本。

### 1.4 软件用途

本软件用于Web应用端到端自动化测试的录制和脚本生成环节，适用于采购管理、行政审批、电商交易等各类业务流程的测试场景。测试人员无需手工编写测试脚本，通过简单的浏览器操作即可自动生成高质量的自动化测试脚本。

## 3 安装说明

### 3.1 安装步骤

**步骤1：获取软件包**

将软件源代码目录复制到本地工作目录。

**步骤2：安装Python依赖**

```
pip install -r requirements.txt
```

**步骤3：安装浏览器引擎**

```
python -m playwright install chromium
```

**步骤4：验证安装**

```
python cli.py list
```

若输出"尚未录制任何模块"提示，说明安装成功。

### 3.2 配置说明

**登录态配置**：首次使用前需保存浏览器登录状态。

```
python save_login_state.py
```

执行后在浏览器中完成登录操作，登录态将保存到 `login_state/storage_state.json`。

**AI服务配置**（可选）：在 `.env` 文件中配置AI服务的API密钥，用于启用AI依赖推断功能。

## 4 功能说明

### 4.1 功能结构图

本软件包含以下核心功能模块：

- **两步录制器**：编排UI录制和API捕获的两步录制流程
- **AST解析器**：通过抽象语法树解析提取UI操作语义
- **HAR解析器**：解析HTTP Archive文件提取API调用序列
- **脚本转换器**：将原始脚本转换为自愈兼容的增强脚本
- **页面守卫模块**：登录自动恢复和弹窗自动关闭

### 4.2 两步录制功能

#### 4.2.1 功能描述

两步录制是本软件的核心功能，通过分步执行实现UI操作与API数据的自动关联。

**第一步（UI录制）**：启动Playwright codegen工具，打开被测系统的目标页面。测试人员在浏览器中手动完成业务操作（如填写表单、点击按钮、选择下拉选项等），操作完成后关闭浏览器，系统自动保存原始测试脚本。

**第二步（API捕获）**：系统自动在无头浏览器中回放第一步生成的脚本，同时在浏览器上下文中注入HAR录制（捕获所有API请求和响应数据）和Trace追踪（记录DOM快照和操作截图）。回放完成后自动保存HAR文件和Trace文件。

#### 4.2.2 操作步骤

**1. 启动录制命令**

```
python cli.py record create_demand --url https://example.com/demand
```

参数说明：
- `create_demand`：模块名称，用于标识本次录制的业务模块
- `--url`：被测系统的目标页面地址
- `--project`：项目名称，可自动获取URL配置
- `--headed-step2`：第二步回放使用有头模式（调试用）

**2. 在浏览器中完成业务操作**

系统自动打开浏览器并导航到目标页面。测试人员按照业务流程进行操作，例如：
- 在输入框中填写需求名称
- 从下拉列表中选择品类
- 点击"提交"按钮
- 等待页面跳转和操作结果

操作完成后直接关闭浏览器窗口。

**3. 自动回放与数据捕获**

系统自动进入第二步，在无头浏览器中回放刚才的操作，同时捕获：
- API请求/响应数据（保存为HAR文件）
- DOM快照和网络时间线（保存为Trace文件）

**4. 查看录制产物**

录制完成后，产物保存在 `output/modules/<模块名>/` 目录下：

| 文件 | 说明 |
|------|------|
| raw_script.py | codegen生成的原始脚本 |
| api.har | 完整的API请求/响应数据 |
| trace.zip | DOM快照和操作截图 |
| enhanced_script.py | 自愈兼容的增强脚本 |
| recording_summary.json | 录制摘要信息 |

### 4.3 脚本重放功能

#### 4.3.1 功能描述

对已录制的模块重新执行回放，重新生成HAR和Trace文件。适用于被测系统接口变更后需要重新捕获API数据的场景。

#### 4.3.2 操作步骤

```
python cli.py replay create_demand
```

参数说明：
- `create_demand`：已录制的模块名称
- `--headed`：使用有头模式回放（可观察操作过程）

### 4.4 AST解析功能

#### 4.4.1 功能描述

本软件内置基于抽象语法树（AST）的脚本解析器，能够精确提取Playwright codegen生成的Python脚本中的UI操作语义信息。

解析能力包括：
- 识别链式调用（如 `page.get_by_role('button', name='提交').click()`）
- 提取选择器类型（role、text、test_id、label、placeholder、css等）
- 提取操作动作（click、fill、select、check、hover、press等）
- 提取操作值（输入框的填写内容、下拉框的选择项等）
- 支持多层嵌套调用链的自动解包

#### 4.4.2 解析策略

解析器采用三级策略确保高覆盖率：

| 优先级 | 策略 | 说明 |
|--------|------|------|
| 1 | AST函数级解析 | 遍历test函数体中的表达式语句，解析调用链 |
| 2 | AST全局解析 | 当无test函数时，解析所有表达式 |
| 3 | 行级正则解析 | AST无法解析时的兜底策略，按行正则匹配 |

### 4.5 HAR解析功能

#### 4.5.1 功能描述

解析HAR（HTTP Archive）1.2标准格式的JSON文件，从中提取业务API调用序列。

#### 4.5.2 解析能力

- **URL模式过滤**：支持通配符模式（如 `**/api/**`），只提取匹配的API请求
- **静态资源过滤**：自动排除图片、CSS、JS、字体等静态资源请求
- **预检请求过滤**：自动排除OPTIONS预检请求
- **大JSON截断保护**：对超过阈值的响应体进行递归截断，保留语义信息的同时控制数据量

### 4.6 脚本转换功能

#### 4.6.1 功能描述

将codegen生成的原始Python脚本自动转换为自愈兼容的增强脚本，同时注入变量提取桩和三层断言桩。

#### 4.6.2 转换规则

| 转换项 | 转换前 | 转换后 |
|--------|--------|--------|
| 页面对象 | `page` | `healing_page`（支持自愈） |
| 函数签名 | `def test_xxx(page: Page)` | `def test_xxx(healing_page)` |
| 类型导入 | `from playwright.sync_api import Page` | 移除Page类型 |
| 变量提取 | 无 | 注入变量提取桩 |
| 断言验证 | 无 | 注入三层断言桩 |
| 时间戳 | 无 | 注入时间戳变量（避免数据重复） |

#### 4.6.3 噪音清洗

自动识别并清洗以下录制噪音：
- 同一输入框的冗余click（聚焦操作，fill前的click）
- 同一输入框的连续fill（只保留最后一次）
- 连续fill之间的冗余press（如全选后删除的中间步骤）

### 4.7 页面守卫功能

#### 4.7.1 功能描述

在脚本执行过程中提供登录自动恢复和弹窗自动关闭能力，确保录制和回放的稳定性。

#### 4.7.2 守卫策略

**登录守卫**：在页面跳转后被动检测，发现被重定向到登录页时自动执行登录恢复。优先使用从录制脚本中提取的登录操作（最精准），其次使用环境变量中配置的账号密码。

**弹窗守卫**：在操作失败时检测是否有遮挡性弹窗，通过ESC键或点击关闭按钮自动关闭弹窗后重试操作。

### 4.8 已录制模块查看功能

#### 4.8.1 操作步骤

```
python cli.py list
```

输出示例：

```
已录制模块 (3 个):
   ✅ create_demand (15 UI操作, 8 API)
   ✅ audit_demand (10 UI操作, 5 API)
   ✅ confirm_demand (8 UI操作, 4 API)
```

### 4.9 增强脚本生成功能

#### 4.9.1 操作步骤

对已录制的模块单独生成增强脚本：

```
python cli.py generate-script create_demand --extract-vars demand_id:POST /demand/create:data.id
```

参数说明：
- `create_demand`：模块名称
- `--extract-vars`：指定需要提取的变量（格式：`变量名:API路径:字段路径`）

## 5 运行说明

### 5.1 典型使用流程

**第一步：保存登录态**

```
python save_login_state.py
```

**第二步：录制业务模块**

```
python cli.py record create_demand --url https://example.com/demand
```

**第三步：查看录制结果**

```
python cli.py list
```

**第四步：生成增强脚本**

```
python cli.py generate-script create_demand
```

### 5.2 常见问题处理

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 录制脚本为空 | 未在浏览器中操作 | 重新录制，确保在浏览器中完成操作后再关闭 |
| HAR文件未生成 | 回放过程中脚本执行失败 | 使用 `--headed-step2` 参数观察回放过程 |
| 登录态失效 | storage_state.json过期 | 重新执行 `save_login_state.py` |
| 选择器失效 | 前端页面变更 | 使用自愈功能自动修复 |

## 6 技术特点

1. **两步录制法**：首创将UI操作录制和API数据捕获分为两步执行，通过时间戳自动对齐，无需人工关联
2. **AST精确解析**：基于抽象语法树而非正则匹配，精确提取UI操作语义，覆盖率更高
3. **智能噪音清洗**：自动识别并去除录制噪音，生成精简可维护的测试脚本
4. **页面守卫机制**：自动处理登录失效和异常弹窗，提升录制和回放的稳定性
5. **大JSON截断保护**：对API响应中的大数据量进行递归截断，保证后续处理的稳定性
